01Overview

DroneSplat tackles two core problems when reconstructing 3D scenes from real-world drone photos: moving objects (cars, people) that break the “static scene” assumption, and limited viewpoints (some areas are seen by only a few photos).

The key idea

  • Adaptive Local-Global Masking — hides dynamic-object pixels from the loss, with a threshold that adapts automatically.
  • Voxel-guided 3DGS — initialize from multi-view stereo (DUSt3R) + optimization constrained by a voxel grid, keeping geometry accurate when views are sparse.

What we did

  • Built the CUDA environment from scratch (Windows + RTX 4080).
  • Ran the full pipeline on 2 scenes: Simingshan & Sculpture.
  • Built interactive viewers: 3DGS orbit & 360° panorama.

The flow we ran for each scene:

SAM2 segments every instance per image → masks.json

2
3DGS Training

7,000 iterations, L1+SSIM loss with per-instance masking (--use_masks)

3
Render

Re-render train & test images from the Gaussian model

4
Evaluation

Compute PSNR / SSIM / LPIPS vs ground truth

A gotcha we hit: SAM2’s default config (sam2_hiera_l.yaml) resolves to an empty stub file → error Key 'model' is not in struct. Fix: use --model_cfg configs/sam2/sam2_hiera_l.yaml. Training uses instance threshold --preset_instance_threshold 0.4 and starts masking at iteration 500 — both are exactly the paper’s values (λL=0.4, masking active at 500).

06The problems the paper solves

① Dynamic scenes (distractors)

Moving objects (cars, pedestrians) violate the multi-view consistency assumption of 3DGS/NeRF → artifacts & floaters.

Prior methods: semantic segmentation (needs predefined classes, can’t tell a parked car from a moving one) or residuals (fail on the small distractors typical of drones). Many use a fixed threshold throughout training.

② Limited viewpoints

In a single flight, some areas are captured by only ~3 photos. Radiance fields then overfit to the inputs → poor novel-view quality.

InstantSplat uses MVS priors (DUSt3R) for initialization, but adds no constraint on the subsequent 3DGS optimization, so that rich prior is wasted.

07Overall framework

Two pillars work together on top of 3DGS:

A
MVS Priors

DUSt3R predicts a dense point cloud + confidence from unposed photos

B
Point Sampling

Confidence + geometric-feature (FPFH) sampling per voxel

C
Voxel-guided 3DGS

Gaussian initialization + voxel-constrained optimization

D
Adaptive Masking

Object-wise residual → adaptive local mask + global mask (SAM2 tracking)

3DGS loss with mask:  L = (1−λ)·M·LL1 + λ·M·LD-SSIM   → the more accurate the mask M, the fewer the artifacts.

08Adaptive Local-Global Masking

Goal: identify dynamic-distractor pixels and hide them from the loss — without predefined classes, and with a threshold that adapts per scene & training stage.

Step 1 — Object-wise normalized residuals

Compute the residual between render and GT, normalize L1 & D-SSIM, and combine. SAM2 provides a mask per object; all pixels of one object share a single average residual value.

R̃ = (1−λ)·R̃L1 + λ·R̃D-SSIM   |   Robj = mean of R̃ over the object’s pixels

Step 2 — Adaptive Local Masking

Instead of a fixed threshold, it is derived from the residual statistics of the frame: expectation + variance, with a relaxation early in training (when objects haven’t converged yet).

TL(t) = E[R] + Var[R]·( 1 + λL · (Tmax−t)/Tmax )

Objects whose average residual > TL are flagged as distractors. Almost all static objects fall within 1 standard deviation of the expectation → those exceeding the threshold are dynamic.

Step 3 — Complement Global Masking

Problem: an object may be temporarily still (e.g., a car stopped at a red light) and slip past the local mask in that frame. Solution: a stricter global threshold (λG > 1+λL); once an object ever exceeds TG, it becomes a tracking candidate — 5 prompt points (center + 4 edges) are fed to SAM2’s video tracking to flag it across all frames.

TG = E[R] + λG·Var[R]   |   Final mask:   M(t) = Mlocal(t) ∪ Mglobal(t)
Intuition: the local mask = “what looks dynamic right now”; the global mask = “objects ever caught moving, tracked across all frames.” The two complement each other.

09Voxel-guided Gaussian Splatting

Goal: accurate geometry even with limited views, by exploiting MVS priors without letting 3DGS “run away” during optimization.

Geometric-aware Point Sampling

DUSt3R produces a dense point cloud (often over-parameterized & with position drift). Instead of using all of it, the paper filters: space is split into N voxels, each point scored by confidence × geometric FPFH feature, and only the top-k points per voxel are kept to initialize Gaussians.

Score(p) = Conf(p) · F̃PFH(p)   → keep the k highest-scoring points per voxel

Voxel-guided Optimization

Each Gaussian is “bound” to its voxel. If its center/scale exceeds a limit (τ × voxel length) it is flagged unconstrained; its gradient decays exponentially with distance from the voxel center. New Gaussians are only split/cloned into an empty voxel once the accumulated gradient passes γ₁. “Junk” voxels (too few Gaussians < γ₂, or average opacity < γ₃) are removed.

Hyperparameters (paper): λL = 0.4λG = 2.8N = 80 voxels k = 3τ = 3.5γ₁ = 0.003 γ₂ = 2γ₃ = 0.0757,000 iters · A100 masking active @ iter 500

10The DroneSplat dataset

The paper releases a dataset of 24 sequences of in-the-wild drone footage — dynamic scenes (split into 3 levels by number of distractors) & static. The experiments use:

  • Distractor elimination — 6 scenes of varying dynamics (including Simingshan & Sculpture, which we used), each with enough images to avoid sparsity.
  • Limited-view reconstruction — 2 static scenes with only 6 input views.
  • Also evaluated on NeRF On-the-go & UrbanScene3D.

Each component contributes. On dynamic scenes, adding Local Masking → Global Masking → Voxel-guided improves quality step by step:

On DroneSplat-static, the voxel-guided ablation shows: MVS priors alone + vanilla 3DGS actually hurt quality (over-parameterization), while point sampling + voxel-guided optimization push it to the best result (PSNR 16.0 → 18.1).

13Main contributions

  • The first robust 3DGS framework designed specifically for in-the-wild drone imagery — removing dynamic distractors while addressing unconstrained optimization under limited views.
  • Adaptive Local-Global Masking — combining local & global segmentation heuristics with a statistical approach for superior distractor elimination.
  • Voxel-guided 3DGS — geometric-aware point sampling + voxel-guided optimization, leveraging MVS priors without losing 3DGS’s representational capacity.
  • A released dataset of 24 sequences of in-the-wild drone footage (dynamic & static).
